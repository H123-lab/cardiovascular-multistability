# Figure Data Catalog and Matrix Mapping

This subdirectory catalogs the raw matrices and plot vectors utilized by the parent directory's rendering scripts.

## Data Reference Matrix
*   `figure_3_data.csv` — Contains transient single-cycle column arrays for $P_{LV}$, $P_a$, and $V_{LV}$ generating the baseline pressure-volume loop configuration.
*   `figure_4_data.csv` — Houses the bidirectional step-continuation coordinates tracking the saddle-node split thresholds across the systemic vascular afterload vector.
*   `figure_5_data.csv` — Stores the divergent time-series tracks documenting the 8.5 s resilient recovery phase vs. the 13.0 s state failure crossover.
*   `supp_figure_s4_data.csv` — Logs numerical step refinement calculations proving discretization step-independence down to $< 0.027\text{ mmHg}$.

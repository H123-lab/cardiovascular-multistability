# Raw Post-Stress Volumetric Divergence Logs

This folder houses the transient convergence and transition tracking trajectories recorded during acute delta stress tests inside the bistable parameter window ($R_{sys} = 1.40\text{ mmHg}\cdot\text{s}\cdot\text{mL}^{-1}$).

## Data Profiles Captured
* `system_a_recovery_raw.csv`: Tracks the transient trajectory of a resilient system absorbing a 10% volumetric stress and returning to its original baseline orbit basin within $\le 8.5\text{ s}$.
* `system_b_transition_raw.csv`: Tracks a fragile system crossing the unstable separatrix boundary and shifting into an alternative high-pressure equilibrium branch.
